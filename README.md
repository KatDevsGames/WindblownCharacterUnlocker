# Windblown Character Unlocker

## Overview
The Windblown Character Unlocker is a mod for the game Windblown that allows players to unlock all characters instantly.
This was created with the intention of allowing players to pick the character they find most affirming without the need
to have purchased the game during a time-gated sale or having to meet high-difficulty unlock requirements.

## Installation
1. Install MelonLoader, a modding framework for Windblown. You can find at https://melonloader.co/#download.
   1. When prompted to select which MelonLoader version to install, select "Enable Nightly Builds" and select 0.7.2-ci.2388.
2. Run Windblown once with MelonLoader to generate the necessary folders.
3. Exit Windblown.
4. Download the Windblown Character Unlocker mod from the [releases page](https://github.com/KatDevsGames/WindblownCharacterUnlocker/releases).
5. Place the downloaded `.dll` file into the `Mods` folder located in your Windblown installation directory.
6. Launch Windblown. All characters should now be available for selection.
